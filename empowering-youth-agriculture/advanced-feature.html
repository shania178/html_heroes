ADVANCED FEATURE

CSS-Variable Driven Theme Toggle

A single checkbox switch reassigns CSS custom properties at the body level — every component on the page updates automatically with zero per-element overrides for standard elements.

1. Define Variables in :root

Light-theme values are declared once on :root. Every component references var(--bg), var(--surface), var(--text), etc.

2. Reassign in body.dark-mode

When the toggle adds the .dark-mode class, the same variables are reassigned to dark values. All components update automatically — no extra selectors needed.

3. Persist with localStorage

The user's preference is saved in localStorage and restored on page load, so the theme survives navigation and browser restarts.

/* Light mode — :root */ :root { --bg: #f0f7ee; --surface: #ffffff; --text: #1a2a1a; } /* Dark mode — same variables, new values */ body.dark-mode { --bg: #111c11; --surface: #1c3021; --text: #ecf2e9; }
